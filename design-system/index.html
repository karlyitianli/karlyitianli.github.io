Design system

Tokens and components for this personal website, copied from the Framer project karls.design. One page, no framework, live on GitHub Pages.

What this is

The source of truth is Framer, project karls.design, Home page. This page documents the tokens and components as built in HTML, CSS, and JavaScript on GitHub Pages, so the next page can reuse them without opening Framer.

Principles

  • Exact copy first: same tokens, same spacing, same text styles as Framer.
  • One shared set of variables: colours and type live in :root and in the text style presets, not scattered through components.
  • Static and light: no build step, public Framer image URLs, Phosphor icons from a CDN.
  • Hover is information: contact rows dim to 0.5 opacity and show a cursor tooltip, cards are links where they lead somewhere.

Stack

  • Fonts: Inter 4.000 from Framer's own font files, DM Mono from Google Fonts.
  • Icons: Phosphor, @phosphor-icons/web 2.1.1, regular weight.
  • Images: public framerusercontent.com/images/ URLs, not committed to the repo.
  • Hosting: GitHub Pages, repo karlyitianli.github.io, branch main.

Background grid

The page background is a 21 by 21px grid SVG, stroke #121212 at 0.07 opacity, tiled over Surface. Same asset on every page.

Typefaces

Inter for everything except the small location and clock labels, which are DM Mono. Inter is loaded from Framer's own Inter 4.000 files, not Google Fonts, because Google's static Inter strips the character variant features. OpenType features cv03, cv04, cv09, cv11, blwf are on everywhere. In Inter 4, the single-storey "a" is cv11, not cv03.

Vancouver Clock

Live clock, America/Vancouver, hour and minute with AM/PM and short timezone name, DM Mono 12px, Muted, with a Phosphor Clock icon 16px in Icon grey. The colon blinks every second, 1 second steps animation, on for half a second, off for half.

Cursor tooltip

A shared pill that follows the mouse, offset 16px right and down, clamped to the viewport. Fill Muted #7e7e7e, radius 99px, padding 8px 12px 8px 8px, gap 8px, white 14px text, 20px Phosphor icon. Resume and LinkedIn read "Open tab" with Arrow Square Out. Email reads "Copy" with Copy, and switches to "Copied!" for 1 second after clicking. The native pointer cursor stays visible. Touch devices show no tooltip.

Spacing

Scale in use: 4, 8, 12, 16, 20, 24, and 40px. Key values: 24px between sidebar sections and between cards, 12px inside card headers, 8px gaps in contact links and tooltips, 40px padding at the bottom of the card list.

Radii and borders

  • Sidebar and case study cards: radius 16px, 1px Border.
  • Portrait and card logos and preview images: radius 12px.
  • Download button: radius 8px, 1px Border.
  • Cursor tooltip: radius 99px, no border.
  • Contact rows: no radius, 1px Border bottom only.
